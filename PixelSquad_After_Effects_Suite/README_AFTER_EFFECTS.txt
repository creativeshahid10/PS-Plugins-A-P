HOW TO INSTALL:
----------------------------------------------------------------------
[WINDOWS]:
1. Is folder mein di gayi "Install_PixelSquad_After_Effects_Windows.bat" 
   par Double-Click karein.
2. Administrator popup (Yes) maange toh Yes karein.
3. Script automatically saare panels install kar degi.
4. After Effects open karein:
   Menu: Window > Extensions > PixelSquad Motion Studio / Text / Tools!

[macOS]:
1. "Install_PixelSquad_After_Effects_Mac.command" par Double-Click karein.
2. Setup complete hone ke baad After Effects open karein.
